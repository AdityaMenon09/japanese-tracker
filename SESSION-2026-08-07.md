## 1. The re-theme

The tracker had its own quiet, paper-and-Mincho look; the landing page that now
sits in front of it is rounder, warmer and more playful. Clicking through felt
like changing sites. This closes that gap — the app now speaks the landing
page's visual language.

**What was borrowed, verbatim, from `index.html`:**

- **Palette** — washi cream (`#F4EEE2` / `#FFFFFF`) with the vermilion seal
  (`#E0674D` / `#C64A31`), plus the sakura and gold accents.
- **Type** — **Mochiy Pop One** for display, **Zen Maru Gothic** for body *and*
  Japanese, **Baloo 2** for numbers. The Japanese text moved off Yu Mincho onto
  the rounded Zen Maru Gothic, so JP and EN are set in one voice like the
  landing page.
- **Claymorphism** — soft layered shadows (`--shadow-clay`), big rounded
  corners, a white inset highlight, and a lift on hover.
- **Pill buttons** with gradient fills and press animations.

**What was newly built to carry that language into the app:**

- A **gradient hero banner** at the top: a peach→cream sky (dark: aubergine→
  surface), the landing page's round 3-D seal, a faint floating-kana wash in the
  corner, and glass streak / Home / Reset chips.
- **Rounded seal-chip section headers** — each eyebrow's kanji glyph now sits in
  a little gradient seal tile.
- A **safe scroll-reveal**: blocks fade up as they enter view, but only ever
  hide themselves when both motion is allowed *and* `IntersectionObserver`
  exists, so content is never stranded invisible.

Everything stays theme-aware: light and dark both carry a full token set,
including per-theme clay shadows.

## 2. The kana chart

A new **Kana chart** section sits between the Quiz and the Lessons — a reference
you can glance at while drilling.

- Built from the app's existing `KANA` dataset, so the glyphs live in one place;
  **katakana is derived on the fly with `h2k()`** rather than duplicated.
- Three grids: the **gojūon** 46, then **dakuten / handakuten** (voiced), then
  **yōon** (combined sounds). The gojūon and dakuten grids keep true 5-column
  alignment — the gaps in the や / わ / だ rows are real empty cells, so the
  columns line up like a paper chart.
- Two toggles: **Hiragana ⇄ Katakana** and **Romaji on/off**.
- **Tap any kana to hear it**, wired to the same Speech engine as the rest of
  the app.

## 3. Fixes from review

| Where | What went wrong |
|---|---|
| Header banner | At tighter widths the Home/Reset controls overflowed past the banner's right padding and jammed into the rounded corner, because the title block held its intrinsic width and pushed the trailing group out. Letting the title flex-shrink into the leftover space (`flex:1 1 0; min-width:0`) keeps the seal, streak and controls inside the 30px padding at every width. |
| Writing pad (Android) | Drawing with a finger scrolled the page instead — the canvas had the browser default `touch-action:auto`, so Chrome claimed the vertical drag as a scroll and fired `pointercancel` mid-stroke. Root cause was deeper: the writing mode had **no CSS at all** (pre-existing — never styled), so there was no pad, the white ink was invisible on a transparent canvas, and the fixed-pixel canvas width even overflowed the page horizontally. Added the missing writing styles: a real dark pad, a traceable guide overlay, a responsive height, and `touch-action:none` + `overscroll-behavior:contain` on the stage and canvas so a finger-drag draws instead of panning. |

**Not a bug — the sentence-card speaker icon.** It looked missing, but the
`spk(s.j || s.k)` call in the sentence card is byte-for-byte unchanged. `spk()`
only draws the 🔊 when a Japanese voice exists, and this laptop's Chrome has
none — so it is hidden here and shows on phones / Edge, exactly as before. The
"audio is off" banner is the app saying so.
