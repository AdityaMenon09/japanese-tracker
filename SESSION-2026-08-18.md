## 1 · The kanji font

The kanji read as too thick with no space inside the strokes. Cause: **Mochiy Pop One**
(a heavy poster face) for display kanji, and **Zen Maru Gothic** bold for labels. After a
side-by-side sample sheet of ~12 candidates, the pick was **BIZ UDPGothic** — a Japanese
"universal design" gothic built for legibility — at weight **700** for display kanji.

Both pages share the same font stack, and Japanese is cleanly isolated, so the swap was
surgical and left **all English text untouched**:

- **`index.html`** — the `.jp` class → BIZ UDPGothic 700 (the big 日本語, hero title, and the
  red feature-card labels). Dropped the now-unused Mochiy Pop One.
- **`app.html`** — the `--jp` variable → BIZ UDPGothic (covers every Japanese string:
  drills, lessons, vocab, kana, section badges). The three decorative kanji that were on
  the display font — the **継** seal, the **頑張れ** stamp, the **あ ア ん** banner wash —
  moved onto it at weight 700.

## 2 · The translator

A new **English → Japanese** section. The architecture:

- **Translation** — a Vercel serverless function at **`/api/translate`** proxies **DeepL**,
  keeping the API key server-side in the `DEEPL_API_KEY` env var. The client falls back to a
  free no-key service (MyMemory) when the function isn't reachable, so it still works in a
  plain local preview. The proxy call aborts after 6s so a stall can't hang the UI.
- **Furigana + romaji** — a lazy-loaded **kuroshiro + kuromoji** engine (`JPEngine`) runs
  **entirely client-side**. It also exposes a tokenizer (word + reading + part-of-speech),
  which is the shared core the planned song feature will reuse.
- **UX** — a furigana toggle, a "hear it" button (Web Speech), and Ctrl/⌘+Enter to submit.
  The translation shows **immediately**; readings are a best-effort enhancement capped at
  15s, degrading to a "readings unavailable" note rather than a spinner.

### Setup that lives outside the code

- **DeepL** needs an **API plan** (Free tier, 500k chars/month) — separate from a consumer
  DeepL Pro subscription. The auth key ends in `:fx` and lives in the DeepL account's
  *API keys* section.
- In **Vercel → Settings → Environment Variables**: `DEEPL_API_KEY` = the key, marked
  **Sensitive**, scoped to **Production + Preview** (Sensitive vars can't go in Development —
  that's fine, we don't use `vercel dev`). Env-var changes require a **redeploy** to apply.

## 3 · Tabbed navigation

The dashboard was one long scroll (~18 sections). It's now **six click-to-switch views**:
**Home · Translate · Study · Drills · Reference · Progress**, via a sticky tab bar.

The sections are **interleaved in the DOM** (e.g. the Kana chart sits between the two Drills
grids), so rather than reorder the document, each top-level block carries a `data-panel`
group and the tab bar toggles visibility by attribute. Details:

- Deep-links via the URL hash (`#drills`), so a tab is bookmarkable and the back button works.
- The old scroll-reveal is replaced by a per-view fade.
- The Lessons **"Drill lesson N →"** button (in Study) now switches to the Drills view
  before scrolling to the grammar drill.
- 375px: no page overflow in any view; the tab bar scrolls sideways instead of breaking.

## The debugging arc (worth remembering)

The translator worked first try in a Chromium test but misbehaved on the reporter's real
setup (Windows, Firefox/Chrome, Cloudflare WARP + heavy proxying). In order:

1. **Hung 30 min on "reading the Japanese…"** — the kuromoji dictionary never finished
   downloading from its CDN. Fix: show the translation first, cap readings at 15s, and don't
   cache a failed engine load.
2. **Couldn't type in the box** — a "preload the dictionary when the Translate tab opens"
   optimization kicked heavy work onto the main thread and froze input. Fix: removed the
   preload; the dictionary loads only on the Translate press, after the user has typed.
3. **Readings still slow/blocked** — the network was throttling the dictionary CDN itself.
   Fix, and the durable one: **vendored the ~17 MB kuromoji 0.1.2 dictionary into `/dict`**
   and load it same-origin (`dictPath:"/dict/"`). Served as `application/gzip` with no
   `Content-Encoding`, so kuromoji decompresses it itself.

**Lesson:** "works in the test browser" ≠ "works on the user's network." The CDN dependency
was the fragile part; self-hosting removed it.

# Part 2 — song study + lesson "go deeper" links (18–20 Aug)

## Song study (branch `song-feature`, then merged)

A new **Songs** tab (7th tab, after Translate). Flow: paste a **YouTube** link → embeds the
player inline; paste the song's **Japanese lyrics** → **Break it down** tokenizes each line
with the existing `JPEngine` — **furigana over kanji, per-line romaji, every word clickable**.
Tapping a word opens a panel with its reading, romaji, an **English gloss**, and audio (when a
ja voice exists).

- Meanings come from a new **`/api/define`** serverless function proxying **Jisho** —
  server-side, so the user's network can't block it and there's no browser CORS problem.
  Returns `{word, reading, senses}`; edge-cached a day. Verified against the real API
  (沈む → "to sink; to go under; to submerge" …).
- **Lyrics are pasted, never fetched.** A "Find lyrics on Genius ↗" link seeds a Genius
  search from the first line; the user copies the text back. Auto-fetching full lyrics stays
  ruled out — no free/legal API, scraping breaks ToS + copyright.
- Reuses the translator's timeout/degradation pattern so a slow dictionary can't hang it.
- Known limit: the free tokenizer misreads some words (e.g. 二人 as "ni-nin", not "futari").

## Lesson "Go deeper" links

Each lesson now has a **Go deeper** row → **Tae Kim ↗** and **Imabi ↗**. We can't legally copy
their content in (Imabi is all-rights-reserved; Tae Kim is NC-SA at best), so each link is a
**site-scoped Google search** (`site:guidetojapanese.org` / `site:imabi.net`) built from the
lesson's title + grammar points — it lands on that site's page for the exact point, with no
hardcoded URLs to rot and nothing copied. The plan: deepen individual lessons' own text
on demand as the user hits friction while studying, rather than rebuilding all 25 up front.
