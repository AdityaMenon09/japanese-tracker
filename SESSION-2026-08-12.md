# Session log — 12 August 2026

The tracker became an actual **N5 exam-prep tool**. Aditya is sitting the JLPT N5
in December, so five new sections were added to close the gap between "study
habit app" and "prepares you for the real paper" — without touching the existing
Quiz or Flashcards, and without changing the visual language.

Built on branch **`n5-exam-prep`** (not merged, not deployed). Everything is
still one self-contained `app.html`, inline CSS + the single IIFE, no build step.

---

## Why — how the site measured up to the real N5

The 2025 N5 paper has three timed blocks (all four-choice, 90 min, pass 80/180):
**① Vocabulary**, **② Grammar + Reading**, **③ Listening**. The site was strong
on kana and basic SRS vocab but trained *none* of the grammar block, had no
reading-with-questions, no real listening comprehension, and used type-the-answer
rather than the exam's multiple-choice format. These five features target exactly
those gaps.

---

## The five new sections

All new drills share **one small multiple-choice engine** (`runMc`) so the real
four-choice format is baked in once. Each answer locks the options, marks the
correct one green and a wrong pick red, shows an explanation, then a Next button;
scores persist in `state.exam`.

1. **JLPT N5 countdown** — days to the December sitting (hard-set to
   `2026-12-06`, the first Sunday; the weekday label is computed, not hardcoded).
   Shows the three sections, ~90 min, four-choice, pass 80/180, with a note to
   confirm the local date/registration.

2. **Vocabulary by theme** — the "basic stuff": 16 themed decks (Numbers, Days,
   Dates, Time, Time words, Colours, Body, Family, Food & drink, Places, Weather
   & nature, Adjectives, Verbs, Question words, Position, Greetings). Kana + kanji
   + rōmaji + meaning, tap-to-hear, rōmaji on/off. Same card grid as the kana
   chart. Data lives in `THEMES`.

3. **Grammar drills** — `GRAMMAR` bank of 36 fill-in-the-blank questions
   (particles, verb/adjective forms, counters, question words, comparatives,
   existence あります/います, これ/この…). Pick 8/12/20, each explains itself.

4. **Reading practice** — `READING`: four short passages incl. one
   information-finding **notice** (two-column layout, opening hours). Passage
   shown above its comprehension questions, with a native `<details>` English
   toggle. One random passage per round.

5. **Mock exam** — assembles a ~20-question test in real N5 order (Vocabulary →
   Grammar → Reading → Listening) on a 20-minute countdown, scored by section
   with a verdict against the 80/180 pass mark. **Listening only appears where a
   Japanese voice exists** (so it's skipped on this laptop; note is shown). Vocab
   and listening items are generated from `THEMES`.
