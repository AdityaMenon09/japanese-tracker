## The audit — four findings

**1. The Lessons section taught nothing.** Each of the 25 lessons was a label plus
two examples. Lesson 14 in its entirety was:

```
g: "verb groups · Vてください · Vています · Vましょうか"
```

An index entry, not a lesson. Nothing said what the verb groups *are* or how you get
from 待ちます to 待って. And per the 27 July log the only Minna no Nihongo volume on
hand is **II** (N4, lessons 26–50), so there was no book behind the index either.

**2. The drill bank covered the wrong half of the syllabus.** Tallying all 36 items:
**33 tested lessons 1–13**. These had *zero* items — 〜てもいいです / 〜てはいけません
(L15), 〜てから (L16), 〜たことがあります / 〜たり (L19), plain form (L20), 〜と思います
(L21), noun-modifying clauses (L22), 〜とき / 〜と (L23), 〜てあげる・てもらう・てくれる
(L24), 〜たら / 〜ても (L25).

One item was also mis-targeted: `ねる まえに、ほんを ◻。` put the blank on よみます, so it
tested 〜ます and never touched まえに — which is the actual grammar point.

**3. One of the thirteen official question types was being trained.** The
[official 大問のねらい table](https://www.jlpt.jp/guideline/pdf/n5.pdf) defines 13:

| Section | 大問 | Covered? |
|---|---|---|
| 文字・語彙 | 漢字読み, 表記, 文脈規定, 言い換え類義 | none — themed vocab is browse-only |
| 文法 | 文法形式の判断 | **yes** |
| | 文の組み立て | no |
| | 文章の文法 | no |
| 読解 | 内容理解・短文 (~80字) | yes |
| | 内容理解・中文 (~250字) | no |
| | 情報検索 (~250字) | the library notice is ~35 characters |
| 聴解 | 課題理解, ポイント理解, 発話表現, 即時応答 | none — the mock's listening is word→meaning |

**4. The banks were too small to drill.** 36 items at 12 per round means the whole
bank is seen in three sittings, against a plan calling for a daily grammar drill for
16 weeks.

**What checked out:** the countdown facts are right. 90 minutes (20/40/30) and
80/180 with 38/120 and 19/60 sectional minimums both match the
[official test-sections page](https://www.jlpt.jp/e/guideline/testsections.html), and
6 December 2026 is the correct first Sunday.

## What was built

### The lessons

Every lesson gained two fields: `pts` (the grammar written out — a heading, a plain-English
explanation, and an optional table) and `warn` (the mistakes that cost marks).

**100 teaching points · 26 tables · 60 pitfall notes.**

The tables are where most of the value sits — the Group I て-form endings, the two
adjective conjugations side by side, the あげる/くれる/もらう direction grid, the
dictionary-vs-た contrast before とき, the full こそあど grid.

The pitfalls are the specific traps, not general advice: かえる looks like a Group II
verb and isn't; きれい ends in い and is a な-adjective; 「たかいでした」; う-verbs go to
わない not あない; a noun before と needs だ; ある is irregular in the negative.

### The drill bank

Rebuilt from 36 items to **200, tagged by lesson, exactly 8 per lesson across all 25** —
verified by regex count, not by eye.

Two new controls make that reachable:

- a **lesson picker** on the drill (All 25 lessons, or L1…L25)
- a **"Drill lesson N →"** button inside each opened lesson, which preselects that
  lesson and scrolls to the drill

Only **All 25 lessons** runs count towards the best score. An 8-question single-lesson
set would otherwise inflate it — the guard is a `grScored` flag set at drill start.

- Served locally and driven in a browser: no console errors on load.
