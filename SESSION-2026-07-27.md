## 1. Audio

Uses the browser's **Web Speech API**, so the page stays one self-contained file — no audio files, no network calls, no API key.

- **Header control** — Auto (speak on reveal) and a Slow / Relaxed / Normal speed, both persisted.
- **Flashcards** — a "Hear it" button appears below the card once flipped, and the Japanese plays automatically. It sits *below* the card rather than on a face, because in the "kana → reading" direction the Japanese is on the front, not the back.
- **Quiz** — the Japanese plays and gains a speaker button only in the feedback, after the answer is in. Playing it sooner would hand over the answer.
- **Writing practice** — the prompt gains a speaker, so you can work from the sound instead of the rōmaji.
- **Listening quiz** — a new mode: 20 audio-only rounds, kana or words, typed back in rōmaji. Tracks its own best score. Always plays regardless of the Auto setting, since there is no question without it.

### The catch: no Japanese voice on this laptop

Windows has only English voices installed (David, Zira, Mark, Heera, Ravi). Chrome on Windows only exposes voices the OS has, so **audio is silently unavailable there**. The page detects this, hides the speaker buttons and the Listening mode, and shows a dismissible banner instead.

Two ways around it:

- **Microsoft Edge** — ships Japanese voices with nothing to install.
- **Your phone** — Android and iOS both include one. This is where the tracker actually gets used.

To fix Chrome: Settings → Time & language → Language & region → Add a language → 日本語, tick **Speech**, restart the browser.

## 2. Sentence of the day

Sits between the dashboard and the study panels — the first thing after the daily check-in.

Two sentences a day, side by side. One is written purely in hiragana; the other is an everyday sentence built around **katakana loanwords** (コンビニ, スマホ, パソコン).

> **A judgment call worth recording:** the original request was for a hiragana sentence and a katakana sentence. Pure-katakana sentences aren't a thing in real Japanese — katakana marks borrowed words. So the second sentence uses katakana the way it actually appears rather than transliterating a whole sentence into it.

30 and 28 entries, so the pairing doesn't repeat for 420 days. The pair is keyed off the calendar date: stable across reloads, rolls over on its own at midnight.

Two toggles, both persisted, both off by default:

- **漢字** — reveals the natural written form. Off to start, since kanji is months 1–3 of the plan. Says so plainly when a sentence has none.
- **rōmaji** — reveals the reading.

Each sentence has a speaker button that plays the **kanji form** where one exists — speech engines segment words and place pitch far better from natural orthography than from a long spaced-out hiragana string. It sounds the same, only cleaner.

## 3. N5 lesson track

25 lessons in the grammar order of 『みんなの日本語 初級I』, between the study panels and the heatmap. Tap a lesson to see its grammar points and two example sentences with audio; tick it off when done. The first unticked lesson is flagged **next**, so there's always an answer to "what do I study today".

Example sentences were written for this page rather than lifted from the textbook.

### The textbook is the wrong volume

`Downloads\Minna No Nihongo.pdf` is **みんなの日本語 初級II — Translation & Grammatical Notes**, Lessons 26–50. That's roughly **N4**, not the N5 beginner volume. Three independent confirmations:

1. The cover reads 初級**II**.
2. The explanatory notes (p.5): *"There are 25 lessons, from Lesson 26 to Lesson 50, which follow 『みんなの日本語 初級I』"*.
3. The body starts at Lesson 26 — p.30 is Lesson 27 vocabulary.

Two further caveats: it's the **companion** volume (vocabulary, translations, grammar notes) — the drills and dialogues live in the separate 本冊 Main Text. And it's a scanned copy with handwritten margin notes and **no text layer**, so reading it needs page rendering (`pdftoppm`), not text extraction.

**For N5 you need Minna no Nihongo I** (Lessons 1–25), Main Text plus the Translation & Grammatical Notes. What you have becomes useful in roughly 6–8 months.

It did earn its keep, though: pages 20–21 carry Book I's grammar index for Lessons 16–25, which was used to verify the lesson track point by point. Lessons 1–15 follow the standard published order.

## 4. Rōmaji → kana, and the sentence bank

Every lesson has a **My sentences** box. Type the Japanese in rōmaji, watch it become kana as you type, add an English note, save it against that lesson. Saved sentences get a speaker button and a delete control.

```
watashi ha BAIO no kaisha de hataraite imasu.
        ↓
わたし は バイオ の かいしゃ で はたらいて います。
```

Lowercase gives hiragana, **CAPITALS give katakana**. Particles follow real IME convention — you type `ha` and `he` for は and へ — so this doubles as practice for an actual Japanese keyboard.

Converter details: longest-syllable-first matching, っ from doubled consonants (plus the `tch` spelling in *matcha*), the ん rules, and long vowels in katakana (`KOOHII` → コーヒー, not コオヒイ). Verified against 31 cases.

### Why this instead of English → Japanese

The original request was to type **English** and have the site translate it. That can't be done in a static page — it needs a translation engine, which means an API key, which means a serverless function and a bill.

It was built that way first (a Vercel function holding the key server-side, since the repo and site are both public), then reverted once the numbers were on the table:

| | Cost |
|---|---|
| Vercel hosting | **Free** — Hobby tier |
| Rōmaji→kana converter | **Free** — ~90 lines of JavaScript in the browser |
| English→Japanese via API | ~**1–1.5¢ per sentence** on Opus 5, ≈ $7/month at 20/day |

There was also an exposure problem: the endpoint would be public, so anyone who found it could burn the credits.

The serverless function and `package.json` were deleted. The page remains a single self-contained file that works offline.

> An earlier estimate in this session put the API cost at "a fraction of a cent per sentence." That was wrong — the arithmetic hadn't been done. The real figure is roughly 1–1.5¢.

## Bugs found and fixed

| Where | What went wrong |
|---|---|
| Flashcard audio | The speaker was attached to the card's back face, so in "kana → reading" — where the Japanese is on the *front* — it never appeared. Moved below the card, revealed on flip. |
| Mobile header | Adding the audio control made the header wrap badly: seal, title and streak each took their own row. Fixed with a flex-basis on the title. Ended up **210px tall against 227px before** — shorter than the original despite the extra control. |
| `konnichiwa` → こんいちわ | The `nn` rule always consumed both n's. It should only do that when no vowel follows: こんにちわ is ko-**n**-**ni**-chi-wa. |
| `SUUPAA` → スーパア | `slice(0, 4)` on a shorter string returns the whole thing, so a trailing vowel matched at length 4 instead of 1 and skipped the long-vowel check. Only visible when the doubled vowel ended the input — `KOOHII wo kudasai` passed while bare `KOOHII` failed. |
| SDK version | `@anthropic-ai/sdk` was pinned at a guessed `^0.70.0`; the real current version is `0.115.0`. (Moot after the revert, but the guess would have shipped.) |
| Deploy verification | A local-vs-live file comparison first reported a mismatch. That was an encoding artifact — `Get-Content -Raw` decoded the UTF-8 Japanese as ANSI. Re-read as UTF-8, the files matched exactly. |
